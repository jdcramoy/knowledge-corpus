1. trials-factor (dissent-wave3-trials-factor)
   - Idea: permutation-null calibration of the dreamer's best-of-N pattern mining, so a max-statistic bar separates real patterns from confabulation (wave's #1 leverage pick).
   - Verdict: MATERIAL — science correct, spec unbuildable as written: dream reports carry no per-pattern numeric score, and the LLM-prose null violates CONTRACTS zero-LLM with no budget.
   - Survives: rescoped to dream-mine.py enumerable digests over session-intact day-swap permutations — built and live, with the real finding that the dreamer's best pattern sits WITHIN the null; LLM-prose null deferred pending an explicit budget.

2. fdt-gate (dissent-wave3-fdt-gate)
   - Idea: MAD-based noise-floor gate that books ZERO when an improvement claim is within metric noise, audited monthly by the evidence agent (2nd leverage pick).
   - Verdict: MATERIAL — gate math sound, insertion point empty: value-ledger derive() books constant heuristic hours, so there are no delta-claims or metric series to sigma-gate.
   - Survives: retargeted to a defined improvement-claim record format over real series — built as fdt-gate.py (σ = MAD×1.4826), proven by booking a real 2026-10-10 claim within-noise-floor with a bad_instrument flag; compensating rows only, never rewrites.

3. trigger-hierarchy (dissent-wave3-trigger-hierarchy)
   - Idea: L0/L1/L2 prescaling hierarchy with a minimum-bias random bypass sample and a novel-events stream, pitched as the fleet's biggest cost win.
   - Verdict: MATERIAL — the stream is never named and both readings break (prescaling the dreamer's input degrades the unfolded-rate repeats signal; leaving the dreamer full-corpus saves nothing), and 0.1-1% bypass is an empty sample at fleet volumes.
   - Survives: built as L0-only trigger.py — config-driven globs, prod/P0 express line, count-floor bypass (>=10/day or the whole stream bypasses), novel stream banked (50 events on first run); L1/L2 remain stubs for the integrator and the EV is unproven until a named spend line exists.

4. ratchet-recombination (dissent-wave3-ratchet-recombination)
   - Idea: genome ledger + ratchet counter where every prompt clause must re-earn its place against the fixture suite, recombination sending failures dormant-never-deleted.
   - Verdict: MATERIAL — no oracle can re-earn a prompt clause (fixtures test recipes and harness invariants, never clauses), fitness signals are per-agent/per-ticket not per-patch, and insurance guards always look benefit-less.
   - Survives: items 1-2 built (patch-genome.py + ratchet-watch.py, report-only, trip = exit 3, instruction-patch mirroring live); recombination stays gated behind a clause-to-oracle registry plus a never-recombine class for hook/config-enforced guards — neither exists yet.

5. coincidence-bus (dissent-wave3-coincidence-bus)
   - Idea: independence accounting for bus corroboration — a dependency registry plus joint-significance coincidence scoring across agents posting together.
   - Verdict: MATERIAL — the ±10min window structurally never fires on the fleet's real cadences (channels run 100-130 min apart), auto-escalate contradicts the read-only rollback and the gossip-read.py edit ban, and the premise was patched the same day.
   - Survives: built as read-only coincidence.py with cadence-aware windows (max(10min, 1.5× channel interval) — measured watchdog interval 113.1 min), union-find shared-upstream collapse, 24-channel registry; escalation stays a patch note to Josh, never a self-write.

6. fusion-neff (dissent-wave3-fusion-neff)
   - Idea: N_eff = N/(1+(N−1)ρ̄) accounting plus a κ>0.5 diversity invariant to refuse bogus fusion panels (the kimi-family unanimous-wrong incident class).
   - Verdict: MATERIAL — fusion.jsonl has no verdict field and prediction ledgers are agent-keyed, so labeled joints are months away, and the pessimistic default would refuse ALL panels including Josh's explicit P0 calls (authority inversion).
   - Survives: instrument-first built — outcome-labeling CLI on fusion.jsonl, static same-family ban live (advisory, never refuses a Josh-requested fusion), κ math gated at >=30 labeled joints per pair; enforcement remains deferred and Josh-gated.

7. pleiotropy-gates (dissent-wave3-pleiotropy-gates)
   - Idea: consumer-degree blast-radius graph assigning trust rungs by fan-out, uncountable consumers = maximal pleiotropy.
   - Verdict: MATERIAL (narrow) — rule 3's >=5-consumer module-split mandate would force a shared-library bugfix (atomic_io.py, ~20 consumers) into an incoherent module split, and the graph duplicates synaptic-strength.py without stating the relationship.
   - Survives: built as pleiotropy.py reusing and extending synaptic-strength's graph, with the interface-stability exemption added and prompt-embedded rules maximal; live read: 141 items → 103 josh-gate / 25 propose / 13 auto-safe.

8. qd-archive (dissent-wave3-qd-archive)
   - Idea: MAP-Elites archive over (failure-class × loop-touched × blast-radius) breeding variants against a mechanical evaluator, mutation riding the nightly dreamer (highest-ceiling card).
   - Verdict: MATERIAL — replay-gym is a 1-bit invariant checker not a fitness gradient, the specced fitness selects confident junk via the dreamer's self-estimated P(accept), and the variant artifact class was never pinned.
   - Survives: built as elites.py with 168 cells, fitness restricted to benchmarkable-only signals (runtime/assertions/coverage), P(accept) banned twice (argparse + payload linter), replay-gym pass as a binary floor; decay on re-eval failure, not visit-count.

9. spore-portfolio (dissent-wave3-spore-portfolio)
   - Idea: ~10% ε of off-policy spore runs on alternate models with spore-vs-dominant divergence as early warning against gateway monoculture.
   - Verdict: MATERIAL — the geometric-mean objective targets per-session returns that do not exist (cost-governor: no job/class/model attribution), flooring negatives breaks bet-hedging economics, and spores.json would be a third routing authority with undefined precedence and no enforcement-point owner.
   - Survives: built SHADOW-ONLY as spore-router.py + config/spores.json (returns-series schema, ε=0.10 per-class, divergence detector); cost-governor untouched via 3-patch note, precedence honored — ε-reserve routing and the objective are Josh-gated deferrals.

10. affinity-maturation (dissent-wave3-affinity-maturation)
    - Idea: detectors that caught something get sharper — constrained-grammar mutations of claim scope/quantifiers, variants kept when they catch more of the failure class, never_auto stays Josh-gated.
    - Verdict: MATERIAL — claims.jsonl rows are prose with nothing for the grammar to bind to, one fixture per class makes "catches more" unmeasurable, fire counts are unknown (titer-report: no last_fired), and no negative fixtures exist for the autoreactive screen.
    - Survives: built instruments-only as affinity-mature.py (loop deferred to wave 4) — slot-parser honestly flags 15/15 claims as prose, grep usage counter live (clm-001 = 19 files, top maturation priority), negative-fixture registry seeded with 4 real class negatives.
