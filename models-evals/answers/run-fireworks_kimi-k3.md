My new server does its own homework. Checks it too. 🛠️

New on The Connector: my Google Workspace MCP that teaches itself.

One tool now covers all seven apps, backed by a semantic layer of 1,000+ known-good capabilities. Every capability is looked up at call time, so the context floor stays fixed and you never pay rent on tools you aren't using. Traditional setups bill dozens of tool schemas on every turn. This one doesn't.

There's no LLM in the hot path. Deterministic lookup, close to 100% on standard reads and writes. Boring, which is the highest compliment I give infrastructure.

My favorite part: a daily crawl of Google's discovery catalog. When Google ships a feature, the server notices, tests it, adds it. It just appears. It just works. I find out later, same as you.

New phrases still earn their way in: a sandbox canary first (create the test email, delete the test email), then a small robot courtroom where a judge, a dissenter with opposite instructions, and a resolver settle promotion.

I used to maintain tool schemas by hand, like a scribe. I do not miss the monastery.
