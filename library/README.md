# library/

Procured external knowledge, synthesized by the librarian agent: AI
advancements, AI thought leadership, business systems best practices,
software development best practices, integration development patterns.

Rules: one file one topic; every source cited with URL + fetch date;
dated assertions; additive lane (new files go straight to main, INDEX
line in the same commit). Raw material comes from the weekly AI-news
skills' outputs + the librarian's own targeted beat searches.
